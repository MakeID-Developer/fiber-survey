# FiberSurveyDemo 操作说明

## 身份与连接

- 手机连接的是TR-FID主机，例如TR-FID-000002；`000002`是主机编号。
- 探测器通过主机报告，`content.device_id`如000011、A-1是探测器标签，不是可单独连接的BLE设备。
- 只提供本地BLE功能，不用AppID、AppSecret、账号、Token或网络。
- 首页点扫描选主机，或手工输入主机编号连接；权限申请、蓝牙检查两入口一致。扫描时可停、重新扫描或取消。
- 连接不等于就绪，等待通知onReady后才允许关机。显示MTU和载荷，不自行保证512或21字节以上。

## 数据与日志

上方本地TX/RX/状态日志，下方连接、过滤、关机和事件。日志/事件分别可清空；最新在上，查看历史不会强制跳转。白名单为空全部放行，非空只显示命中探测器的业务事件，JSON和ACK不受影响。

标识保留前导零与符号，A-1不同于A1。power_down/非up可能来自缺失/未知字段，请结合原文诊断，不能仅凭false认定物理功率下降。

## 一键关机

仅在受控环境并有实际授权时操作。确认框显示当前主机和全部范围；白名单不限制关机。点击取消不会发送命令。

确认后等待SDK5秒ACK，App额外总截止为8秒，不重发。成功只表示status=ok，不代表每台探测器已核验断电。超时、断线或释放时结果可能未知，先现场核实。Demo在命令终结后关闭会话，避免迟到ACK被下次命令误认；需重新操作时手工再选主机。

## 取消与退出

整个App退后台会结束会话，主页面跳转扫描页不结束；返回前台需重新选择。取消编号匹配或连接后可能等待旧SDK请求截止（最长约40秒），期间禁止开启另一会话。该等待不是设备资源已彻底释放的证明，实际生命周期还需真机验收。

不自动连接/重连、不恢复旧关机操作。退出清白名单，日志/事件仅保存在本进程内，无文件导出或上传。设备敏感标识分享前须脱敏。
